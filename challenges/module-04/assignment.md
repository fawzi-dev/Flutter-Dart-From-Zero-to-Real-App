# Module 4 Assignment — Shopping-List Stats

**Independent practice (Level 2).** Lists, loops and maps on a fresh dataset.

## Brief
Start from a hardcoded list of grocery prices and print some useful statistics — no input needed for this one; the *logic* is the product.

## Requirements
1. A `List<double>` of at least 6 prices.
2. Print the **count**, the **total** (loop and accumulate — no `.reduce`), the **average** (2 decimals), and the **most expensive** item's price.
3. Print how many items cost **more than the average** (a second pass with a condition).
4. **Bonus with a Map:** given a parallel list of category names, print the total spent *per category* using a `Map<String, double>`.

## Rubric
- [ ] Count, total, average, max all correct and computed (no magic numbers)
- [ ] The "above average" count is right
- [ ] No hardcoded list length anywhere it matters
- [ ] Bonus: the per-category map grows automatically if you add a new category

## Difficulty
**Level 2 — Independent** (the Map bonus is **Level 3**).

⏱️ Minimum 40 minutes.
