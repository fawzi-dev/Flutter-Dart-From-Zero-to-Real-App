# Snapshots of the card, stage by stage

Each file is `lib/main.dart` exactly as it stood at the end of one
lesson. Drop one into `lib/` and run it if you want to see the card at that
point, or diff two of them to see what a lesson actually changed.

| File | Lesson | What it adds |
|---|---|---|
| `step_1_skeleton.dart` | 7.8 | The custom widget, and the shape of the card |
| `step_2_words.dart` | 7.9 | Text, sizes, weights, letterSpacing, ellipsis |
| `step_3_box.dart` | 7.11 | Container, padding, margin, radius, shadow |
| `step_4_photo.dart` | 7.12 | assets, Image.asset, ClipRRect, CircleAvatar, Row |
| `step_5_font.dart` | 7.13 Part 1 | google_fonts, and the const that had to come off |
| `step_6_polish.dart` | 7.13 Part 1 | Palette, AppBar colours, INGREDIENTS heading, rules |
| `step_7_scroll.dart` | 7.15 Part 2 | SafeArea + SingleChildScrollView — same as `lib/main.dart` |

Lesson 7.10 (`const` and your editor) changes no markup — it is about what the
editor is telling you — so it has no snapshot of its own.
