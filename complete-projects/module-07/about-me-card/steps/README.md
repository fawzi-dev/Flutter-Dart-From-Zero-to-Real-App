# Snapshots of the solution, part by part

Each file is `lib/main.dart` exactly as it stood at the end of one of the four
solution videos. Drop one into `lib/` and run it, or diff two of them to see
what a part actually changed.

| File | Lesson | What it adds |
|---|---|---|
| `step_1_content_gradient.dart` | 7.18 Part 1 | Plain Texts, the gradient, SafeArea + SingleChildScrollView |
| `step_2_avatar_name_pill.dart` | 7.18 Part 2 | Ringed avatar, styled name, pill badge |
| `step_3_one_card.dart` | 7.18 Part 3 | ONE info card inline, the red screen, Expanded |
| `step_4_extract.dart` | 7.18 Part 4 | InfoCard extracted and used three times — same as `lib/main.dart` |

Part 1 is meant to look bad. That is the ugly-first rule from the brief, and
stopping there is the correct place to stop.
