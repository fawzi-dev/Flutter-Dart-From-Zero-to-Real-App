# Weather Now — Module 11 challenge solution

The finished Weather Now from the four solution videos, 11.7 P1 to P4. Try the
challenge first (`challenges/module-11/`), then compare.

## Run it

```
flutter pub get
flutter run
```

**The one test that matters:** turn on airplane mode and launch it. A friendly
message and a working Retry — no crash. Turn it off, tap Retry, and the
weather comes back. Then search `asdfgh`: a different message, because a city
that doesn't exist is a different problem from no network.
