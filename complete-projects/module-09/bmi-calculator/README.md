# BMI Calculator — Module 9

The completed BMI challenge is in `lib/main.dart`. Run it with `flutter run`.

Two small pre-challenge demos support the separate input lessons:

| Lesson | Run | Problem solved |
|---|---|---|
| 9.6 Part 4 — Slider | `flutter run -t steps/step_0a_slider.dart` | Keep height within 120–220 cm without parsing text. |
| 9.6 Part 5 — SegmentedButton | `flutter run -t steps/step_0b_segmented.dart` | Keep two short choices visible; the height slider still retains its own value. |

These checkpoints demonstrate inputs only. They do not reveal the completed BMI calculation, result screen, or challenge structure.
