# Steps — BMI calculator

The solution, built from the empty starter in eight steps, one per video.
Each file is `lib/main.dart` at the end of that video.

| File | Video | What it adds |
|---|---|---|
| `step_1_shell.dart` | **9.10 P1** | `AppColors`, `BmiApp`, the empty screen with an `AppBar` |
| `step_2_cards.dart` | **9.10 P2** | `InputCard` and `BigNumber`: Height 175 cm, Weight 65 kg |
| `step_3_buttons.dart` | **9.10 P3** | `StepperButton` and `PrimaryButton`, still doing nothing |
| `step_4_gender_height.dart` | **9.10 P4** | Stateful; `gender` and `height`; the segmented button and the slider |
| `step_5_weight_bmi.dart` | **9.10 P5** | `weight`; the steppers; the `bmi` getter, printed |
| `step_6_result.dart` | **9.10 P6** | `showResult` and `ResultView` |
| `step_7_categories.dart` | **9.10 P7** | `categoryFor`, `colorFor`, `interpretationFor`, `CategoryPill` |
| `step_8_scale.dart` | **9.10 P8** | `BmiScale` and `ScaleBand`. Same as `lib/main.dart` |

Run any one from this folder:

```
flutter run -t steps/step_5_weight_bmi.dart
```
