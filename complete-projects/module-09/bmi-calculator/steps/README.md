# Steps — BMI calculator

The solution video, 9.10, has two stages. Both start from the challenge's
empty starter.

| File | Lesson | What it is |
|---|---|---|
| `step_1_calculates.dart` | **9.10 P1** end | Input view working, a correct BMI (175 cm, 65 kg: 21.2), a placeholder result view. |
| `step_2_marker.dart` | **9.10 P2** end | The finished calculator: result view, scale and marker — same as `lib/main.dart`. |

Run either one from this project folder:

```
flutter run -t steps/step_1_calculates.dart
```

The slider and segmented-button demos that come before the challenge live in
the state playground, not here, so this project stays your own job.
