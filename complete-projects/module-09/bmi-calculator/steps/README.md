# Steps — BMI calculator

The two `step_0` files are **not** stages of the challenge. They are the small
input demos for 9.6 Parts 4 and 5, shown before the challenge is set, so each
one shows a single control and nothing of the finished calculator.

| File | Lesson | What it is |
|---|---|---|
| `step_0a_slider.dart` | **9.6 P4** | One height card: a `Slider` held to 120–220 cm. |
| `step_0b_segmented.dart` | **9.6 P5** | The same card with a Male / Female `SegmentedButton` above it. |

Run any of them from this project folder:

```
flutter run -t steps/step_0a_slider.dart
```

The solution video 9.9 has two stages:

| File | Lesson | What it is |
|---|---|---|
| `step_1_calculates.dart` | **9.9 P1** end | Input view working, a correct BMI (175 cm, 65 kg: 21.2), a placeholder result view. |
| `step_2_marker.dart` | **9.9 P2** end | The finished calculator: result view, scale and marker — same as `lib/main.dart`. |
