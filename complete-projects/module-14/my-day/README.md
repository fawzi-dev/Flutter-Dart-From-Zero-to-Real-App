# My Day — Module 14 capstone

A daily dashboard: a "Today" header with a progress ring, the quote of the day,
then your tasks. Built in the solution videos 14.4 to 14.7.

## Run it

```
flutter pub get
flutter run
```

## Steps and tests

`steps/README.md` explains the four slices the app is built in, and holds one
runnable file: the controllers-in-build bug, on its own. `flutter test` runs
the logic tests from lesson 14.9.
