# About Me Card — Starter

A static profile card — your first Flutter build (Module 7).

## Your mission
Full brief + rubric: the **About Me Card Challenge Brief**, in the Challenge: About Me Card lesson (also in the course repo at `challenges/module-07/about-me-card.md`).

## Run it
```
flutter pub get
flutter run
```
You should see an empty screen with a TODO in `lib/main.dart`. Everything visible in the finished app, **you** type.

## Recommended first
Before you start building, run `git init` in this folder and make a first commit once the starter runs. Then build in small checkpoints instead of one giant commit at the end.
