# My Day Cloud — Starter (Module 16 bonus)

**This is the exception to the minimal-starter rule.** It contains the complete
Module 14 app, because Module 16 is about *adding* Firebase to an app you
already understand — not building one from scratch.

**If you built your own My Day in Module 14, use yours instead.** This copy is
here for anyone who skipped the capstone or wants a clean base.

Right now tasks live in memory and disappear when the app closes. By the end of
Module 16 they will live in the cloud, behind a login, syncing across devices.

## Start here
1. Run it and confirm it works: `flutter pub get && flutter run`
2. Follow lesson 16.2 to create a Firebase project and run `flutterfire configure`
3. Build along with lessons 16.3–16.8

Finished reference: `complete-projects/module-16/my-day-cloud/`
