# BMI Calculator — Starter (Module 9 challenge)

An empty app. You build the BMI calculator from scratch.

The colours, the text and the spacing are already written for you, at the top
of `lib/main.dart`: `AppColors`, `AppStrings` and `AppSpacing`. Use them.

The brief is `challenges/module-09/bmi-calculator.md`.

## Run it

```
flutter pub get
flutter run
```
