# State Playground — Starter

The playground for Module 9. One empty screen, so every lesson is only about
the idea being taught: buttons, a screen that changes, text fields and input.

## Run it
```
flutter pub get
flutter run
```
You should see an empty screen called Buttons. In 9.1, you replace the
`SizedBox()` inside the `Center` in `lib/main.dart` with your first button.
Later lessons add one new screen below the last and point `home:` at it.
