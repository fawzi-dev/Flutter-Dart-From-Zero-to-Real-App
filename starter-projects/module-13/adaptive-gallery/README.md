# Adaptive Gallery — Starter

One screen that reflows from a phone list to a tablet grid, in a theme that follows the system's light/dark setting — with a toggle to override it (Module 13).

## Your mission
Full brief + rubric (including the ready-made content list to lay out): `challenges/module-13/adaptive-gallery.md` in this repo.

## Run it
```
flutter pub get
flutter run
```
You should see a near-empty screen with a TODO in `lib/main.dart`. Resize the window (or rotate a tablet / use `flutter run -d chrome` and drag the edge) to watch your layout reflow.
