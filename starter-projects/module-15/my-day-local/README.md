# My Day (local) — Starter (Module 15)

**This is the exception to the minimal-starter rule.** It's the complete Module 14
My Day app — because Module 15 is about *adding* local storage to an app you
already built, not building one from scratch.

**If you built your own My Day in Module 14, use yours instead.** This copy is here
for anyone who wants a clean base.

Right now the tasks live in memory and vanish the moment you close the app. By the
end of Module 15 they'll be saved on the device and load themselves on startup.
